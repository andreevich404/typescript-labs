## Лабораторная работа №8 — Основы TypeScript. Практикум в Node.js

Девять консольных задач: перегрузки, типы данных, функции-сторожи,
иммутабельные операции, обобщения, reduce, класс хранилища и глубокая заморозка.
Каждый `src/taskN.ts` содержит реализацию и примеры с выводом в консоль.
Ожидаемые исключения обрабатываются через `try/catch`.

Проверено на **Node.js v24.22.0**, npm 11.19.1. Зависимости разработки —
TypeScript и `@types/node`; точные версии зафиксированы в `package-lock.json`.
Компиляция: ES2022, ES-модули, NodeNext, `strict` и `noEmitOnError`.

## Установка и запуск

```sh
npm ci
npm run check
npm run build
node dist/task1.js
```

Для другой задачи замените номер: `node dist/task9.js`.
После изменения исходников повторите `npm run build`.

```sh
npm start   # все девять задач после сборки
npm test    # сборка и автоматические проверки граничных случаев
```

TypeScript компилируется через `tsc`, полученный JavaScript запускается через
Node.js. Папки `node_modules/` и `dist/` исключены из Git. Деплой не требуется.

## Задачи и ожидаемые результаты

| № | Файл | Результаты примеров |
| --- | --- | --- |
| 1 | `src/task1.ts` | `42.50`, `TypeScript`, `2026-01-15T12:00:00.000Z`; три перегрузки, `instanceof`, `switch` и проверка `never`. |
| 2 | `src/task2.ts` | Red: `#ff0000`, Green: `#008000`, Blue: `#0000ff` с соответствующими RGB. Канал 256 вызывает обработанный `RangeError`; также запрещены дроби, отрицательные числа, NaN и бесконечность. |
| 3 | `src/task3.ts` | UUID даёт профиль с исходным id; `invalid-id` и число 123 отклоняются сторожем. Проверяется формат, версия UUID не ограничена. |
| 4 | `src/task4.ts` | Добавление `npm`, сохранение массива при повторном `ts`, удаление всех `ts`; объединение даёт `['ts', 'node', 'TS', 'npm']`. Обе исходные коллекции остаются прежними; результаты — новые массивы. |
| 5 | `src/task5.ts` | Один шаг: `10`; два: `Число: 10`; три: `ЧИСЛО: 10`. Несовместимая цепочка с number → string-входом оставлена в комментарии с объяснением. |
| 6 | `src/task6.ts` | Смешанный набор: `{ paid: 150, free: 35 }`; пустой: `{ paid: 0, free: 0 }`. `free` тоже суммируется, входные записи не меняются. |
| 7 | `src/task7.ts` | Числа: `[[1,2],[3,4],[5]]`, строки: `[['a','b'],['c']]`, пустой вход: `[]`. Размеры 0, −1, 1.5, NaN, ±Infinity вызывают обработанные `RangeError`. |
| 8 | `src/task8.ts` | Создание, поиск, обновление года и удаление Book. Повторный id вызывает обработанную ошибку; после удаления поиск/обновление дают `undefined`, повторное удаление — `false`. Смена id запрещена типом и при выполнении; поверхностные копии защищают сохранённый id от внешней мутации. |
| 9 | `src/task9.ts` | `Object.isFrozen()` даёт `true` для корня, пользователя, настроек, массива, книги и метаданных. Примеры запрещённых изменений вложенных полей и массива закомментированы. |

`deepFreeze` замораживает переданный объект на месте и возвращает его с типом
`DeepReadonly<T>`. Область применения по заданию: примитивы, null, обычные объекты
со строковыми ключами и массивы без циклов. Функции, Date, Map и Set не входят
в эту область. Хранилище не изолирует вложенные объекты глубокими копиями.
