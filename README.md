# Лабораторная работа №8 — Основы TypeScript

Девять консольных задач на типы, функции, коллекции, обобщения и классы в Node.js.

## Автор

- ФИО: Толкачев Иван Андреевич
- Группа: ФИТ-241

## Запуск

Используемая версия Node.js: **v24.22.0**.

```sh
npm ci
npm run check
npm run build
node dist/task1.js
```

Для запуска другой задачи замените номер файла (`task1.js` — `task9.js`).
После изменения исходников повторите сборку.

## Задачи и результаты примеров

| Файл | Задача и ожидаемый результат |
| --- | --- |
| `src/task1.ts` | Перегрузки форматирования: `42.50`, `TypeScript`, `2026-01-15T12:00:00.000Z`. |
| `src/task2.ts` | RGB и enum: красный `#ff0000`, зелёный `#008000`, синий `#0000ff`. Для канала 256 обрабатывается `RangeError`. |
| `src/task3.ts` | Брендированный UserId: корректный UUID возвращает профиль; строка `invalid-id` и число 123 отклоняются. |
| `src/task4.ts` | Добавление и удаление тегов; объединение даёт `['ts', 'node', 'TS', 'npm']`. Исходные массивы не меняются. |
| `src/task5.ts` | Pipeline из 1–3 шагов: `10`, `Число: 10`, `ЧИСЛО: 10`. Несовместимый вызов закомментирован с объяснением ошибки типов. |
| `src/task6.ts` | Суммы через reduce: `{ paid: 150, free: 35 }`, для пустого массива — `{ paid: 0, free: 0 }`. |
| `src/task7.ts` | Разбиение: `[[1,2],[3,4],[5]]`, `[['a','b'],['c']]`, пустой вход — `[]`. Для размеров 0, −1, 1.5, NaN и ±Infinity обрабатывается `RangeError`. |
| `src/task8.ts` | CRUD книг: создание, поиск, обновление года и удаление. Дубликат id вызывает обработанную ошибку; поиск и обновление отсутствующей записи дают `undefined`, удаление — `false`. |
| `src/task9.ts` | Глубокая заморозка: `Object.isFrozen()` возвращает `true` для корня, вложенных объектов, массива и его элементов. Запрещённые присваивания закомментированы с объяснениями. |
